# PriorSight Prototype

Front-end only prototype (React, TypeScript, Tailwind, shadcn/ui, Vite). No backend. All patient data is synthetic.

## Run
```
npm install
npm run dev
```
Open http://localhost:5173

## Build
```
npm run build
npm run preview
```

## Screens
Order Entry, Patient Timeline, Admin Insights. Use the patient dropdown to switch between the three synthetic patients.
